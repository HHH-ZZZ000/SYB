## 设计思路与理念

### 产品故事驱动

课程以 **Memory Pendant（视觉记忆挂坠）** 的产品概念为统一叙事主线。这不是一个纯技术实验集合——每个案例都对应产品中的一个真实环节：设备"看见并识别"（视觉 MVP）、"听懂并控制"（语音 MVP）、最后统一为"说一句话，拍一张图，生成一条可回看的记忆"（系统 MVP）。

### 三层递进：最小案例 → 扩展案例 → 综合案例

每个主题拆为三个层次：

- **微课最小案例** — 只建立"能运行并产生直观现象"的最小功能，如 sin 模型拟合曲线、10 秒 PCM 录音、按键触发一次状态迁移。一个微课视频可覆盖，学生能在最短时间内看到"它动了"。
- **扩展案例** — 加入真实硬件、异常处理、性能分析和多任务协作，如猫狗模型替换 sin、WAV 保存与回放验证、三场景 VAD 稳定性测试。这部分在课程实训中完成，学生自己动手测量、比较和排查。
- **综合案例（第 10 集扩展）** — 将视觉、语音、存储和状态机组织为一次完整的记录闭环，验证"任一动作失败→错误恢复"的回退路径。

### 先动手运行，再理解原理

每个案例的 README 统一以"摘要 → Quick Start → 预期现象"开头，学习目标和原理讲解放在后面。学生先跑通代码、看到现象，建立感性认识，再回头理解为什么这样设计。原理讲解只讲本案例需要的概念，不堆砌理论。

### 分层语音：待机只跑轻量模型

语音设计采用"待机→唤醒→命令→动作→待机"的分层模式：待机时只运行 WakeNet（资源占用低），唤醒后才启动 MultiNet（识别具体命令），有效命令后才启动拍照、录音和视觉推理等高负载任务。这种设计既实现了唤醒词与命令词的分离，也控制了计算负载——高负载任务只在事件触发时短时运行，不持续占用资源。

### 由简入繁：逐步替换"假"为"真"

多个关键环节采用"先假后真"的策略降低入门门槛：

- **模型**：sin（数学拟合）→ 猫狗（真实图像分类）
- **语音输入**：SD 卡 WAV 文件 → 板载麦克风实时采集
- **状态机动作**：模拟 mock 返回确定性事件 → 真实摄像头/录音/推理/保存

每一步都复用一个已验证的接口，替换只发生在内部实现，上层逻辑（状态机规则表、识别流程）一行不改。

### 硬件独立，后端可选

ESP32-S3-EYE 独立运行是基础验收路径。Orange Pi + Qwen2-VL 是可选的家庭 AI 中心增强，不属于基础 MVP 的硬性依赖。所有核心功能（拍照、录音、识别、保存、状态反馈）都必须在无网络、无 Orange Pi 的环境下可运行、可验收。

## 案例总览

本仓库按"微课最小案例 → 扩展/作业案例 → 综合案例"组织，共 10 个微课、12 个扩展/作业案例。

| 集数 | 微课案例（最小可观察产出） | 扩展 / 作业案例 |
|:---:|---|---|
| 1 | **训练 sin 模型** — PyTorch MLP 拟合正弦曲线并导出 ONNX | **猫狗模型训练** — MobileNetV2 在公开数据集上训练分类模型 |
| 2 | **量化 sin 模型** — ESP-PPQ 量化 ONNX 为 .espdl | **猫狗模型量化** — 量化猫狗分类模型并导出 .espdl |
| 3 | **运行 sin 推理** — ESP32 加载 .espdl 预测并输出结果 | **静态图片推理** — SD 卡加载猫狗模型与图片推理 |
| | | **实时猫狗分类作业** — LCD 实时预览 + 分类，记录帧号与耗时 |
| 4 | **实时推理调优** — 切换推理核心与 CPU 频率，测量耗时 | **推理优化版** — 任务隔离、FPS、帧年龄与系统稳定性 |
| | | **卡顿 Trace** — Chrome Trace JSON + Perfetto 端到端时间线 |
| 5 | **麦克风录音** — 板载 PCM 采集 10 秒，串口显示进度 | **录音保存验证** — WAV 存 SD 卡，回放验证格式与内容 |
| 6 | **VAD 检测** — AFE + VAD 输出 SPEECH / NOISE | **VAD 稳定性** — 安静/说话/噪声三场景误触发与抖动测试 |
| 7 | **WakeNet WAV** — SD 卡 WAV 唤醒词检测 | **WakeNet 实时** — 板载麦克风 + AFE 实时采集唤醒 |
| 8 | **MultiNet 命令** — 唤醒后识别固定命令并输出编号 | **命令词绑定** — 自定义命令词映射到模拟动作 |
| 9 | **语音性能** — 三种模式耗时与内存测量 | **语音资源预算** — 六组（模式 × 频率）配置矩阵 |
| 10 | **状态机设计** — 按键触发状态迁移，串口日志 | **状态机验证** — 真实拍照/录音/推理/保存闭环 |
