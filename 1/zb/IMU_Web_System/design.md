# 智能传感监控平台 · 设计规范

## Visual Direction
专业工业物联网监控界面。以实验室仪器面板为参考：浅灰工作台、白色数据面板、墨色文字、细分隔线。数字是第一视觉层级。禁止渐变、玻璃拟态、装饰性大图、夸张阴影和 SaaS 宣传式排版。系统名为“智能传感监控平台”；所有用户可见的标题、状态、按钮、提示、图表说明及无障碍标签统一使用中文。保留设备型号、X/Y/Z 轴标识、物理单位及必要的技术缩写；变量、接口字段与代码标识不因界面中文化而改名。部署与操作说明使用中文。

## Layout System
桌面优先，面向 1920×1080 工作台。四层结构为：64px 全局系统栏、工作台标题与紧凑设备摘要、三栏实时监控、全宽历史记录。主体最大宽度 1920px，设备摘要桌面高度约 80px。系统栏区分服务器与设备状态；展开服务器状态可查看实时推送或轮询详情，避免常驻重复提示。中间依次为实时测量、实时加速度趋势、真实摄像头窗口。底部保留最近 6 条真实历史记录、设备采样时间与实测接收频率。历史区“共 N 条记录”使用服务器 total_samples，不使用浏览器最多 2000 条的曲线缓存冒充数据库总数。设备未连接时保留完整布局，不制造示例数据。

## Grid
≥1280px 使用 12 个加权 CSS Grid 轨道，三块分别跨 3 / 6 / 3 轨道，形成约 19% / 54% / 27% 的内容宽度。区块间距 20–24px，页面水平留白 24–32px；三块卡片上下严格对齐，标题和工具栏位于卡片内部。中心绘图区弹性填满主体，图例置于右上，底部仅保留窗口点数和北京时间。历史记录横跨主体宽度。四组测量共用标签、右对齐数值、单位三列。摄像头保持 4:3，不拉伸或裁切真实画面。

## Typography
正文：Segoe UI、Microsoft YaHei、system-ui。数值、设备标识、时间、轴标签：Cascadia Code、Consolas、monospace。系统名 16px/600；页面标题 24–28px/600；面板标题 17px/600；传感器数字 30–34px/500；正文 14px；辅助标签 12px；次要数字 13–16px。数值使用 tabular-nums，正文行高 1.5。所有字体本地回退，无外部字体请求。布局兼容浏览器较大最小字号设置，合加速度标签保持完整。

## Color System
- Workspace: `#f3f4f5`; surface: `#ffffff`; subtle surface: `#f8f9fa`。
- Primary text: `#20292f`; secondary: `#626e77`; muted: `#737f88`。
- Border: `#dde2e5`; strong border: `#c9d1d6`。
- Online / axis X: `#18745b`; online surface: `#edf6f1`。
- Axis Y: `#b57024`; axis Z: `#527d9d`。
- Warning: `#8e571d`; warning surface: `#fff8ee`。
- Error: `#b43c36`; error surface: `#fff3f1`。
颜色只表达状态或区分数据轴。所有状态必须同时提供文字，不能只依赖颜色。

## Spacing
基础间距采用 4/8/12/16/20/24/32px。面板内边距统一为 16–20px；测量行最小高度 60–64px，并随卡片伸展；图表预留坐标文字空间。桌面窗口按钮组和冻结按钮均为 36px 高，手机为 40px。

## Border Radius
面板 8px，按钮与状态标签 6px。只有状态圆点允许圆形。无大圆角容器，无卡片阴影。

## Component Style
系统栏底部 1px 实线；面板边框 1px，无阴影。标题与辅助单位同排。轴标签由小色条和 X/Y/Z 字母组成。设备状态块显示设备名、连接状态、接收时间、样本总数；未收到数据用破折号“—”，禁止用零冒充读数。陀螺仪仅提示“陀螺仪模块未连接”，不绘制虚构读数。按钮使用细边框和清晰的键盘焦点，选中状态用墨色底。工具栏只提供有效操作：“30 秒”“60 秒”“120 秒”窗口与“冻结曲线”“恢复曲线”。冻结曲线时设备状态、数值、历史记录和视频仍继续更新。

## Chart Style
原生 Canvas 实现，完全本地运行，不依赖 CDN。QMA6100P 加速度及合加速度单位统一为 g，保留重力分量；合加速度仅由真实 XYZ 计算。X/Y/Z 使用固定颜色，线宽 1.6px，无填色、发光和大面积动画。淡色水平网格、等宽坐标文字、自动缩放 Y 轴。横轴按服务器接收时间 UTC+08:00 绘制，设备采样时间单独显示；超过 10 秒的断流使用断线表示。指针悬停显示真实采样值。仅绘制实际上传并已入库的记录，刷新和断线重连后读取数据库历史；按记录编号去重，实时缓存上限 2000 条，覆盖目标 10Hz 下的 120 秒窗口。底部表格最多每秒更新一次；高频推送下合并同帧绘图请求，不插值生成采样点。

## Camera State
摄像头通过同源 `/api/camera` 显示真实 MJPEG 视频。在线状态来自服务器近期取得的真实视频帧，与设备三轴在线状态独立判断。未连接、断流或画面请求出错时隐藏旧画面，显示浅中性背景、摄像头图标、“摄像头离线”和“等待视频流 · 连接恢复后自动重试”；不使用图片、动画或循环录像作为替代。底部紧凑状态栏显示 320×240、服务器实测 FPS 与实时/等待状态；无实际帧率时显示“— FPS”，不伪造延迟。错误后延迟重试，隐藏页面关闭视频请求；恢复页面后重新检查状态。视频失败不停止三轴数据和曲线更新。

## Responsive Rules
≥1280px：三栏监控区，1440px 以下缩小内边距并使用 30px 数字。768–1279px：测量与趋势在第一行，摄像头独占下一行。<768px：依次为状态、测量、趋势、摄像头、历史的单列布局，页面留白 16px，顶部与工具栏可折行，图表高度至少 272px。历史表格只在自身可聚焦容器内横向滚动；360px 页面不得横向溢出。缩放时重新计算 Canvas 尺寸，时间刻度数量根据可用绘图宽度减少，避免 HH:mm:ss 标签重叠。

## Motion and Accessibility
按钮、选中窗口和状态颜色使用 160ms 过渡；无弹跳、发光或实时读数闪烁。prefers-reduced-motion 下关闭过渡。服务器详情使用原生 details/summary，可用键盘展开；窗口/冻结保留 aria-pressed，交互控件与历史滚动区域具备可见焦点。状态同时提供文字和颜色，真实离线读数明确标注已过期。截图检查不等同于完整读屏或无障碍认证。

## Loading State
首次请求时显示“正在连接”、数字破折号“—”、图表内文字“正在加载历史数据…”。不使用伪造数据。正常使用 WebSocket 实时推送，重连时用真实历史补齐；推送断开时回退为约 200ms 的串行增量轮询，遇到错误退避，避免请求重叠。设备与摄像头综合状态每 2 秒查询。隐藏页面关闭推送、视频和数据请求；恢复可见时重新连接并补齐历史。连接到服务器不等同于设备在线。

## Error State
服务器请求失败与设备断流分开描述：服务器不可达时状态为“服务器连接异常”，显示“无法连接服务器，正在自动重试。当前保留的上次测量值可能已过期。”，保留最后已知数值并标记“上次测量值 · 已过期”，自动重试。接口拒绝的上传不改变设备在线状态。图表历史加载失败须明确提示，不显示空图假装成功。

## Offline State
服务器按最后成功入库的接收时间判断，超过 10 秒未收到数据时显示“设备离线”。告警文字为“数据未更新，请检查设备连接。”。首次无记录时显示“等待设备连接”和连接/上传提示。断流后保留最后真实读数并标注“上次测量值 · 已过期”，曲线不继续生成点。重新接收真实数据后自动恢复“设备在线”。

## Design QA Checklist
最终以浏览器实际渲染检查：工业风格、4/8 间距体系、数字层级、克制配色、6–8px 圆角、中文标签、桌面三卡对齐、4:3 摄像头、历史总数与手机无溢出。窗口、冻结/恢复、连接详情和键盘焦点须实际操作。硬件离线时只能验收真实离线状态及已有历史，不声称验证了实时曲线或视频播放。本轮仅更新前端及本规范，审查截图、尺寸记录、改动边界与未验证项保存在 `.qa/design-audit-20260917/`，不改变硬件、后端、采集或传输逻辑。
